# Contributing

ScheduleIO welcomes reproducible bug reports, compatibility fixtures, scheduling and codec tests,
documentation corrections, and focused code improvements.

Read the repository's [contributing guide](https://github.com/kestermckinney/ScheduleIO/blob/main/CONTRIBUTING.md)
for the information to include in an issue, the test commands to run, fixture privacy guidance, and
pull-request expectations.

Useful starting points:

* [Open an issue](https://github.com/kestermckinney/ScheduleIO/issues/new)
* [Browse current issues](https://github.com/kestermckinney/ScheduleIO/issues)
* [Review field coverage](Reference/FieldCoverage.md)
* [Build and test locally](GettingStarted/Building.md)
